# SeatHarbor branding and compatibility

SeatHarbor is maintained by githubuser733 as an independent, unofficial fork of [Anode](https://github.com/skulitom/Anode), originally developed by skulitom. It is not affiliated with or endorsed by the upstream author.

- Use **SeatHarbor** and `assets/seatharbor.svg` for this repository and its own public-facing documentation.
- Refer to Anode for accurate attribution, upstream documentation, upstream releases, and technical compatibility. Do not present SeatHarbor as an official Anode release or imply upstream endorsement.
- Preserve the upstream MIT license and copyright notice, Git history, and GitHub fork relationship. See [LICENSE](LICENSE).
- The legacy executable, namespaces, installed MCP registration, configuration paths, Windows credentials, original icon assets and package identifiers are intentionally retained in this source snapshot for compatibility. Existing installed binaries are not renamed by this documentation change.
- Do not publish independent binaries, plugins, marketplace listings or MCPB packages under the upstream identity. Before an independent release, migrate application display name, icon, publisher and package metadata, use distinct distribution identifiers, and validate installation, upgrade, rollback, MCP registration, credentials, and launcher behavior on Windows. Preserve old identifiers only where explicitly needed for compatibility.
- Upstream installation instructions install upstream Anode, not SeatHarbor. No independent SeatHarbor installer is supplied at this stage.
